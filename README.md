## 🌟 مميزات النظام الأساسية
1. **فحص لحظي تفاعلي (Real-time Evaluation):** يتفاعل شريط القوة بالألوان (أحمر، أصفر، أخضر) والنسبة المئوية فور إدخال الحروف.
2. **كشف الكلمات الشائعة والمسربة:** فحص فوري للكلمات ضد قائمة سوداء لأشهر الكلمات المخترقة مثل `123456` و `password` مع خفض النسبة وإظهار تنبيه فوري.
3. **مولّد كلمات مرور عشوائية:** إنشاء كلمات مرور قوية بطول 16 خانة تجمع الأحرف الكبيرة والصغيرة والأرقام والرموز.
4. **نسخ مباشر للحافظة:** دعم زر النسخ عبر تقنية الويب الحديثة `navigator.clipboard`.
5. **إظهار وإخفاء الكلمة:** زر تبديل سلس بأيقونة العين لتسهيل مراجعة الكلمة.

---

## 🛡️ إثبات الخصوصية والأمان (100% Client-Side)
* **انعدام التخزين (Zero Storage):** لا يتم استخدام أي قاعدة بيانات أو تخزين في الـ `LocalStorage` أو ملفات تعريف الارتباط `Cookies`.
* **انعدام الاتصال الخارجي (Zero Network Requests):** تعمل كل خوارزميات الفحص محلياً في جهاز المستخدم عبر لغة JavaScript دون إرسال أي طلبات (HTTP/API) لأي خادم، مما يضمن بقاء كلمة المرور سرية تماماً.

## 🛠️ التقنيات المستخدمة
* **HTML5:** بناء هيكل الصفحة وعناصر الإدخال.
* **CSS3:** تنسيق الواجهة، الحركات الانسيابية، وتجاوب الشاشة.
* **JavaScript (Vanilla JS):** برمجة منطق الفحص الرياضي والتوليد العشوائي.
